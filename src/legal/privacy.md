Umbra 是一款私人 AI 助手，包括电脑端（macOS / Windows）、iPhone 端、Android 端（开发中）和设计软件 UmbraStudio，以及支撑它们的 Umbra 服务器。本政策说明我们（【待填：运营主体全称】，以下称「我们」）在你使用 Umbra 时收集哪些个人信息、为什么收集、存在哪里、交给了谁、保存多久，以及你如何查看、导出、更正和删除它们。

先说三件最重要的事：

1. **不登录也能用。** 客户端默认可以单机使用，提醒、常用语、保险箱、剪贴板、截图、启动器、生活账本、灵感等功能的数据只存在你自己的设备上。只有你登录账号并使用联网功能时，相关数据才会上传到我们的服务器。
2. **保险箱是零知识加密的。** 密码保险箱在你的设备上加密，服务器只保存它解不开的密文。我们看不到你的主密码，也看不到保险箱里的内容。
3. **AI 功能会把内容发给大模型服务商。** 你和秘书对话、让它识别截图或票据、整理记忆、问知识库时，相关文字或图片会经我们的服务器转发给第三方大模型服务商处理。下文第三节列出了具体是哪几家。

## 一、我们收集哪些信息，用来做什么

### 1.1 账号信息

| 信息 | 用途 | 说明 |
| --- | --- | --- |
| 邮箱地址 | 注册、登录、找回密码、发送验证邮件 | 登录凭据，必填 |
| 密码 | 登录验证 | 服务器只存密码的哈希值（PBKDF2-SHA256，60 万次迭代），不存原文 |
| 显示名、头像 | 在各端账号页展示 | 选填 |
| 邀请码 | 注册时核对 | 目前注册采用邀请制，一码一号 |
| 登录会话 | 保持登录、在账号页列出「登录设备」、让你踢下线某台设备 | 服务器只存会话令牌的哈希值；同时记录设备名、创建时间、最近使用时间、下线时间 |
| 邮件验证 / 重置密码令牌 | 验证邮箱、重置密码 | 只存哈希值，记录发往的邮箱地址、到期时间和是否已使用 |

【待核：身份服务正在调整。2026-10-18 已决定去掉第三方开源身份服务 Casdoor，改回 Umbra 自建账号体系，或改为多产品共用的「账号中心」，后者尚未拍板。发布前按届时线上实际情况改写本节。】

### 1.2 设备信息

| 信息 | 用途 |
| --- | --- |
| 设备 ID、设备名称、平台（如 macOS / iOS）、设备支持的能力清单、首次与最近在线时间 | 让你在一个账号下管理多台设备，把任务派给指定的电脑执行 |
| 设备令牌（只存哈希值与展示用的前缀） | 让你的电脑以「设备」身份连接服务器；你可以随时吊销 |
| iPhone 推送令牌（APNs device token）及其环境 | 给你的 iPhone 发提醒等通知 |

### 1.3 你主动存进 Umbra 的内容（登录并使用联网功能时）

使用以下功能时，你输入或上传的内容会保存在我们的服务器上，用于向你提供功能、在你的多台设备之间同步：

- **聊天记录**：你和秘书的对话，包括你发送的图片。
- **任务**：任务目标、执行步骤、执行结果、事件时间线。
- **提醒、常用语、灵感**：内容、时间、配图。登录前只存在本机，登录后同步到服务器。
- **记账**：流水、分类、周期规则、账本（生活账本 / 经营账本）、凭证图片和发票文件。生活账本可以先在本机记，登录后再同步。
- **知识库**：你上传或从电脑同步的文档（服务器上以 git 仓库保存），以及为检索生成的文本分块和向量。
- **保险箱**：只有**密文**，见第 1.5 节。
- **文件**：上述功能里的图片和附件。服务器记录文件名、类型、大小、尺寸、SHA-256 校验值，以及 AI 识图后生成的文字描述。

### 1.4 AI 生成或整理出的信息

- **用户记忆**：为了让秘书更懂你，系统会在对话后用 AI 自动整理一份「记忆」，包括你的偏好、档案（称呼、身份、所在地、背景）、话题、长期在做的事、你提到的人物。你可以在设置页查看、修改、删除，也可以告诉秘书该记住什么、忘掉什么。你还可以把其他 AI 产品里的记忆导入进来。
- **执勤（定时任务与主动提醒）**：如果你开启了早报这类主动功能，系统会读取你的提醒、任务、关注事项，以及你设置的城市（或者记忆档案里的所在地），生成提醒内容。

### 1.5 保险箱（零知识加密）

- 主密码和 Secret Key 只在你的设备上参与运算，**不会上传**。加密密钥由主密码和 Secret Key 派生，条目和附件用 AES-256-GCM 加密。
- 开启同步时，服务器只保存整份保险箱的**密文**、版本号、上传设备的 ID 和更新时间，另外保留最近 10 个历史版本的密文，用于你推错数据时的恢复。服务器没有任何解密能力。
- **因此，你忘了主密码和 Secret Key 时，我们无法帮你找回保险箱里的数据。**
- 保险箱附件的密文也会计入你的存储容量。服务器只知道它的字节数，不知道里面有几个附件、是什么内容。

### 1.6 使用记录与计量

| 信息 | 用途 | 不包括 |
| --- | --- | --- |
| **作息统计**：哪一天、哪个半小时段、哪类操作、操作次数、活跃分钟数、设备类型 | 在设置页向你展示使用记录，并让执勤功能挑选合适的提醒时间 | **不记录任何内容**，只记时刻和计数；后台同步、轮询这类不是你直接操作产生的请求不计入 |
| **AI 用量**：哪个模型、输入 / 输出 token 数、扣了多少额度、日期、从哪个端发起 | 计算会员额度、防止滥用、对账 | 不含对话内容 |
| **存储用量**：各类内容占用的字节数 | 显示「已用 / 上限」，在你超出上限时阻止新的上传 | — |
| **远程控制会话记录**：发起方、被控设备、模式变化、开始与结束时间、连接方式（直连 / 中继 / 快照）、中继流量、延迟 | 让你在设备详情里查看会话记录，计算每月的中继流量额度 | **不记录画面、键鼠输入和剪贴板内容** |

### 1.7 交易信息

你购买会员、充值积分、兑换商品时，我们记录订单号、商品、金额（人民币或积分）、会员折扣、订单状态、付款时间、支付宝交易号、退款时间，以及积分余额和每一笔积分流水。**我们不接触你的银行卡号或支付宝账户密码**，付款在支付宝的页面上完成。

### 1.8 服务器日志

服务器的运行日志会记录请求路径、来源端（PC / iOS / Studio）、会话 / 任务 / 设备的标识和错误信息。**默认不把你的聊天正文、提醒正文、任务目标、发给模型的提示词原样写进日志**，只记长度。只有在开发联调、打开专门的调试开关时，正文才会原样写入，这个开关默认关闭。日志文件单个上限 5 MB，最多保留 5 个历史文件，滚动覆盖。

我们会读取你的 IP 地址做登录限流和防撞库。【待核：反向代理 nginx 的访问日志是否记录 IP，保留多久。】

### 1.10 只在你设备上的数据

以下数据只保存在你的设备上，**我们的服务器拿不到**：

- 剪贴板历史、截图（截图 OCR 在 macOS 本机用系统 Vision 框架完成；截图**翻译**例外，见第三节）、启动器和工作流的本地配置；

我们**不出售**你的个人信息。为了提供服务，下列第三方会接触到部分数据：

你使用以下功能时，相关内容会经我们的服务器转发给大模型服务商处理：秘书对话、识图、截图记账、截图翻译、电脑操控（会把你电脑的屏幕截图发给视觉模型）、记忆整理、灵感整理、知识库问答（文档分块会被向量化）、执勤早报。

| 服务商 | 用于 | 处理的数据 |
| --- | --- | --- |
| 支付宝（中国）网络技术有限公司 | 会员与积分的收款 | 我们发给支付宝：订单号、金额、商品名称；支付宝回传给我们：交易号、交易状态、金额 |

iPhone 端目前**不出售**会员或积分，只显示会员状态和余额。

### 3.5 远程控制

远程控制的画面和键鼠输入走 WebRTC：能直连时，数据在你的两台设备之间点对点传输，**不经过 Umbra 服务器**；直连打不通时，经我们部署的 TURN 中继服务器（coturn）转发。WebRTC 协议本身强制使用 DTLS-SRTP 加密，中继只转发加密的数据包。Umbra 服务器只负责撮合连接（转发连接信令、发放中继的临时凭证），**不解析、不记录信令内容**。

两个例外，请留意：

- **「看一眼」和快照降级**：被控电脑会截一张当前屏幕，**上传到我们的服务器**，再由控制端下载查看。这张截图和其他附件一样存储。【待核：快照截图会保留多久，是否计入存储容量，用完要不要自动删。】
- **建立直连时会用到公共 STUN 服务器**：如果我们没有配置自己的 STUN 服务器，设备会向小米（stun.miwifi.com）或 Cloudflare（stun.cloudflare.com）的公共 STUN 服务器查询自己的公网地址，这些服务器会看到你设备的 IP 地址。Cloudflare 的服务器可能位于境外。【待核：线上是否已经配置自有 STUN 和 TURN（`UMBRA_STUN_URLS` / `UMBRA_TURN_URLS`）、coturn 部署在哪台机器上。】

### 3.6 你自己选择接入的第三方

- **本机命令行 AI 工具**：会员可以让电脑端或 UmbraStudio 调用你电脑上安装的 AI 命令行工具（例如 Claude Code、Codex）。这时内容由该工具直接发给它自己的服务商，适用你和该服务商之间的协议，Umbra 服务器不经手。
- **飞书**：【待核：飞书渠道是否对普通用户开放。如果开放，要写明消息会经飞书开放平台传输。】
- **UmbraStudio 插件**：插件在你的设备上运行。【待核：第三方开发者的插件能访问哪些数据、联网权限怎么管；目前插件新版本要经人工审核才能上架。】

### 3.7 委托处理与公开披露

除上述情形外，我们不会把你的个人信息交给其他人，**也不会公开披露**。以下情况除外：法律法规要求，或者有权机关依法要求；为了保护你或他人的人身、财产安全，且来不及取得你的同意；你明确同意的其他情形。如果发生合并、收购或资产转让，我们会要求新的持有方继续受本政策约束，否则会重新征求你的同意。

## 五、我们怎么保护你的信息

- **传输加密**：客户端与服务器之间使用 HTTPS（TLS）连接；验证邮件和重置邮件走加密的 SMTP（465 端口）。
- **凭据只存哈希**：登录密码（PBKDF2-SHA256，60 万次迭代）、登录会话令牌、设备令牌、邮件令牌，服务器都只存哈希值。
- **零知识保险箱**：见第 1.5 节。
- **按账号隔离**：每条数据都归属到具体账号，服务器按「这次请求是谁」读写，你看不到别人的数据，别人也看不到你的。
- **最小化日志**：默认不记正文，见第 1.8 节；远程控制不记画面和输入。
- **远程控制的安全措施**：只能控制同一账号下的设备；每次会话都要在被控电脑本机点同意（无人值守模式除外，它需要 PIN 并受允许名单和时间窗限制）；被控期间屏幕顶部有提示条，可控时屏幕四周有橙色边框；保险箱窗口不会出现在远程画面里；会员到期、登出或吊销设备时，会话立即结束。
- **备份防勒索**：异地备份使用只能写入的账号，服务器即使被入侵，攻击者也读不到、删不掉历史备份。
- **登录限流**：限制同一来源反复尝试登录，防止撞库。

需要你知道的局限：

- 聊天图片等附件的下载地址本身就是访问凭证（一串不可猜测的随机 ID），**拿到这个链接的人可以直接打开对应的图片**。请不要把附件链接发给不信任的人。【待核：要不要改成需要登录、或者链接有有效期。】
- 服务器上除保险箱以外的数据**不是端到端加密的**。我们的运维人员在必要时（例如排查故障）技术上能够访问，我们通过【待填：内部访问控制制度，例如谁有服务器权限、操作是否留痕】加以约束。

如果发生个人信息安全事件，我们会按法律要求，通过邮件或应用内通知告诉你事件情况、可能的影响、我们已采取和将要采取的措施，以及你可以怎样自行防范，并向主管部门报告。

## 六、你的权利

### 6.1 查看与更正

你可以在各端的账号页查看和修改显示名、邮箱、密码，查看登录设备、会员状态、积分流水和存储用量；在设置页查看、编辑、删除秘书记住的关于你的「记忆」。

### 6.2 删除

- 大部分内容可以在应用里直接删除。删除后先进回收站，30 天后彻底删除，或者你手动清空。
- 「管理存储」页可以按大小列出你在服务器上的文件，删除后立即生效。

### 6.3 导出（复制）

- **记账**：可以导出为表格文件，凭证图片可选择一并导出。
- **保险箱**：电脑端可以导出加密备份，也可以导出不加密的明文 JSON（请妥善保管导出的明文文件）。
- 【待核：目前没有「一键导出账号全部数据」的功能。《个人信息保护法》第四十五条规定了可携带权。要么补上这个功能，要么写明可以通过第九节的联系方式申请导出，以及处理时限。】

### 6.4 撤回同意、关闭功能

- 你可以随时在系统设置里关闭相机、相册、麦克风、屏幕录制、辅助功能等权限。
- 你可以关闭电脑端的「远程访问」总开关，关闭执勤、知识库自动同步、保险箱同步等功能。
- 你可以登出账号，回到单机使用。之后新产生的数据只留在本机。
- 撤回同意不影响此前基于你的同意已经进行的处理。

### 6.5 注销账号

你可以在应用的账号页发起注销。发起后：

1. 所有已登录的设备会**立即下线**；
2. 进入 **30 天**的冷静期，期间你用同一个邮箱和密码重新登录，就会自动取消注销；
3. 30 天期满，账号状态变为「已注销」，邮箱被释放，可以用来注册新账号。

【待核（合规缺口，发布前必须解决）：按目前的代码，冷静期满后用户数据「留在库里，但没有人能登进去看」，**并没有真正删除**（`auth.py` 文件头注释）。2026-10-18 已拍板改为「期满后真删，依法要保留的订单、支付流水除外」（待办 F8），但还没有实现。本节要等这项实现上线后再定稿。另外，目前账号接 Casdoor 时，iOS 端隐藏了「注销账号」入口，这会违反 App Store 5.1.1(v)；切回自建账号后入口会恢复，需要确认。】

注销期满后，我们会删除你的个人信息，或者做匿名化处理。法律法规要求保存的除外，例如交易记录，这部分只保留法定期限。已经进入备份的数据，会随备份到期一并删除。

注销后会员剩余期限和积分余额怎么处理，见《用户协议》第五节。
